## 数据与恢复

- 使用 Android 自带 SQLite，`lx-user-data.db` schema 1；歌单、资料、脚本、历史、统计和设置继续使用明确的存储键。长值按 200,000 字符分块，避免单行超过 CursorWindow。
- 旧 AsyncStorage 数据先完整读取、解开分块及原子快照 generation 指针，再在一个事务中写入新库、恢复副本和迁移标记。失败不提交；再次启动可重试。保留旧库供升级核对，迁移后的读写使用新库。
- 写入和恢复均为事务。完整恢复前保存当前用户数据副本；恢复期间停止旧内存状态写回，完成后必须重启。回退不会恢复已迁出的明文秘密。
- 用户数据位于独立数据库；歌曲、图片、歌词缓存和临时导出文件沿用缓存目录。现有缓存清理不删除用户库或 Keystore 凭据。
- 在既有模拟器数据上覆盖安装后，逐项比较 72 个非秘密、非设置、非运行态对象，72 项一致，保留 21 个源和 2 个用户歌单。设置兼容性和凭据迁移另由行为测试检查。

## 音源与播放

- 每个 QuickJS 实例使用独立运行 ID、能力声明、请求表和生命周期；最多 3 个实例，仅逐出空闲实例，收到销毁完成后才释放槽位。删除、替换、初始化失败和退出会取消对应工作；迟到回调不会落入新实例。
- 每实例 24 MiB JavaScript heap、512 KiB stack、最多 256 个定时器；初始化 10 秒、解析 20 秒，HTTP 每实例最多 24 个并发请求、返回体最多 8 MiB。保留按源控制的更新提示；不把脚本原始请求、响应或任意脚本 console 内容写入应用日志。
- 设置中可选择主音源，对备用源启停、上移、下移。播放按顺序串行尝试音源及匹配歌曲，支持质量降级；全部失败给出明确提示。
- Media3 ExoPlayer 静默 prepare 验证可解码音轨，验证成功才允许写入可复用 URL 缓存。验证不取得音频焦点，最多同时 2 个，8 秒超时。
- 当前播放与预加载分别取消；切歌、源变更、账号凭据变化使旧结果失效。缓存区分源版本、远程 blob、歌曲、目标音质和账号／源世代，最多 128 条、10 分钟有效。
- 原生队列操作串行执行，切轨前暂停；取消时清理该次新增轨道，再处理后续歌曲。轨道 ID 不包含播放 URL。
- 播放栏以独立标签显示音源明确返回的音质。字符串 URL 的返回音质是未知，不用目标音质推断；切歌、失败和源变更清理旧标签。标签不是独立码率测量结果。

## 次数与时长

- 听歌统计 schema 2 增加总次数、按日次数、逐曲次数、计数起点和当前会话。第一次被播放器接受的开始计 1 次；暂停恢复、重复回调、同一会话跨日和进程恢复不重复计数，新一轮手动／自动播放创建新会话。
- 对照桌面 `playback/repository.ts` 的首次会话去重和 `projections.ts` 的首段计数规则，新增手机行为用例；没有把桌面数据库运行包移植到 Android，也没有自动合并两端统计。
- 旧时长完整保留，旧数据没有次数时从 0 开始，界面标明起点；“最常听”可切换按次数／时长前 100 首。
- 播放器初始化前先读取统计和历史，避免恢复歌曲时用空状态覆盖旧统计。熄屏期间仍采样，暂停停止；倍速按实际播放时间折算，跳转不直接增加跳过的时长。

- 网易云、WebDAV 密码和同步认证迁入第二阶段的统一 Keystore 接口；QQ／酷狗继续使用该接口。写入后回读核对成功，才删除旧字段、写迁移标记并清理恢复副本。

- 普通备份不包含平台登录凭据、WebDAV 密码、同步密钥、本地音频、缓存或设备路径。脚本来源信息可往返，恢复不授予账号歌单管理权限。用户自行硬编码在脚本字符串中的秘密不作猜测或篡改，脚本仍按原文备份。
- 导入先校验结构和内容，再映射本机支持的设置，保留 Android 路径和设备偏好。恢复后明确提示新设备需要重新登录或配置认证。

## 验证边界

- QuickJS 2.4 Java 接口没有执行中断 API。上述请求超时和内存／栈／实例限制不等于 CPU 硬截止；恶意无限同步循环无法安全强杀 JavaScript 线程。本次没有宣称完全不可信脚本沙箱，独立进程隔离可作为后续工作。
- 设备验证使用 Android x86_64 模拟器及合成 WAV。arm64-v8a 已构建；实体手机、Android 5、长时间 Doze 和厂家后台限制尚未实测。真实平台登录、私人推荐和第三方音源供应状态延续第二阶段的验收边界。
- 时长按采样累积并节流保存，强制终止可能损失最后一个保存窗口（约 2 秒）；跨日边界按采样归属，不承诺毫秒级账本。完整备份应在稳定状态下导出；多个模块的读取不是单次跨模块数据库快照。
- Android 系统外部打开旧备份文件仍沿用“导入列表”入口；完整恢复使用设置里的“恢复备份或设置”。
- 当前模拟器的系统 DocumentsUI 修复 MIME 筛选后已显示可选文件，但点击未返回文档；系统日志同时存在媒体提供器的 SELinux／存储访问拒绝，尚未确认两者的因果关系，此入口未记为端到端成功。应用已有内置文件选择器完成了真实导入、恢复与回退；它可在设置中选择。
