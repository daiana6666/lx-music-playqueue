## 第一批：下载、本地音乐与歌词阅读

### P4-02 下载管理核心功能（优先）

- [ ] 将下载占位页替换为任务列表，支持添加、取消、失败重试、并发上限和完成文件打开。
- [ ] 支持保存目录授权、文件命名、同名处理、剩余空间检查及空间不足提示。
- [ ] 将后台下载、进度通知、任务持久化和中断恢复一并实现；验证熄屏、切后台、网络变化及进程重启。
- [ ] 明确 URL 过期后的重新解析和失败重试行为，只有服务端与文件校验允许时才支持断点续传。
- [ ] 为下载任务保存明确的音源策略，当前播放源改变时不篡改已有任务；备用源行为对齐桌面下载规则。
- [ ] 将已下载文件与可清理的播放缓存分开，完成状态必须对应实际可读取文件。

验收：下载成功后断网仍可播放；取消、失败和重启不留下假成功状态；目录权限失效和空间不足可处理；重复添加不重复下载。

### P4-01 本地音乐库入口

- [ ] 统一已有本地导入能力与已下载歌曲入口，支持已授权目录查看、重新扫描和授权管理。
- [ ] 对重复扫描、文件移动／删除、无权限文件作去重和失效处理。
- [ ] 支持离线浏览与播放，保留用户歌单对本地音乐的引用关系。

验收：同一文件多次扫描只出现一次；离线播放可用；移动、删除或撤销授权后给出明确状态，不误删用户歌单。

### P4-03 歌词可读性与基础布局

- [ ] 增加歌词字体、行距、翻译间距和上下留白设置。
- [ ] 补充播放栏高度、文字密度与歌曲信息布局设置，保留已有透明度、圆角及边距设置。
- [ ] 验证大字体、横竖屏、安全区域和歌单封面滚动，保证文字不遮挡、按钮可操作。

验收：字号放大和屏幕方向改变后仍能完整操作；设置可持久化；熄屏、悬浮歌词切换不影响播放。
